# Proyecto Q.A.A.

## Objetivo
Desarrollar una página web institucional con
sistema de reservas y panel administrativo.

## Tecnologías
- Python
- Flask
- HTML5
- CSS3
- JavaScript
- SQLAlchemy
- SQLite (desarrollo)
- PostgreSQL (producción)

## Reglas de desarrollo
- Mantener una arquitectura sencilla.
- No modificar archivos innecesariamente.
- Evitar duplicar código.
- Priorizar la seguridad.
- No almacenar historias clínicas.
- Utilizar datos ficticios.
- Explicar los cambios realizados.
- Verificar las funcionalidades antes de
  considerarlas terminadas.

## Idioma
Explicaciones y documentación en español.
Nombres de variables y funciones claros.

## Modo de aprendizaje

- Explicar las decisiones técnicas en español.
- Explicar los conceptos nuevos con ejemplos sencillos.
- Identificar los archivos modificados y su función.
- Explicar la lógica de las funcionalidades.
- Proponer pequeñas pruebas prácticas.
- No generar código innecesariamente complejo.
- Priorizar que el desarrollador comprenda y pueda mantener
  la aplicación.
